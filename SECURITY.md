# Security & Responsible Disclosure

Do not commit credentials, API keys, private keys, mission-data archives, personal data, or local
filesystem paths containing sensitive information.

If you discover a security issue in CHANDRABHAR-2, do not publish exploit details in a public issue.
Contact the project owner privately through the project's established contact channel.

The repository is proprietary; security reporting does not grant permission to copy, modify, or
redistribute the source code.
