# LunaMatch Platform 1.2.0

## Functional workflow completion
- Evidence & Metrics is now an active verification workspace, not an empty placeholder.
- Products & Export now generates and previews JSON, PNG and CSV handoff products.
- Both panels provide actionable experiment controls when no run has been completed.
- Mission Overview shows the latest completed experiment through the workflow status.
- Three-pair experiment results persist in session state and are summarized across OHRC↔TMC2, OHRC↔IIRS and TMC2↔IIRS.
- Added `mission_experiment_summary.csv` for presentation/analysis handoff.
- Added persistent experiment progress and clearer completion state.

## Scientific scope
No changes were made to the v8.0.2 scientific matching engine or its evidence-gate logic. The UI surfaces actual returned evidence and does not manufacture validation.
